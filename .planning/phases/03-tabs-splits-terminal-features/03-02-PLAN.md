<objective>
Add split pane support within tabs so users can divide each tab into multiple terminal surfaces arranged horizontally and vertically.

Purpose: Splits are the second core multi-surface feature after tabs. Each tab needs a tree of splits where leaf nodes are Surfaces with their own child HWNDs, and branch nodes define horizontal/vertical divisions with a split ratio.

Output: Working split panes with creation, navigation, resizing, and closing via performAction dispatch.
</objective>

Create SplitTree.zig implementing a binary tree for split layout:

```
pub const Node = union(enum) {
    leaf: *Surface,
    branch: Branch,
};

pub const Branch = struct {
    direction: Direction, // .horizontal or .vertical
    ratio: f32, // 0.0-1.0, proportion of space for first child
    first: *Node,
    second: *Node,
};

pub const Direction = enum { horizontal, vertical };
```

Key functions:
- `create(alloc: Allocator, surface: *Surface) !*Node` - create a leaf node wrapping a surface.
- `split(alloc: Allocator, node: *Node, direction: Direction, new_surface: *Surface) !void` - replace a leaf node with a branch: the existing surface becomes `first`, the new surface becomes `second`, ratio = 0.5.
- `remove(alloc: Allocator, node: *Node, target: *Surface) !?*Node` - remove a leaf from the tree. If the leaf's parent branch has only one remaining child, collapse the branch to that child. Returns the new root (or null if tree is empty).
- `layout(node: *Node, rect: RECT) void` - recursively compute pixel positions. For branches: divide `rect` according to ratio and direction, recurse into first/second. For leaves: call MoveWindow on the leaf's Surface child HWND to position it at the computed rect.
- `findSurface(node: *Node, target: *Surface) ?*Node` - find the leaf node containing the target surface.
- `focusDirection(node: *Node, current: *Surface, direction: GotoSplit) ?*Surface` - navigate from `current` surface in the given direction (up/down/left/right/previous/next). For directional navigation: find the current leaf's rect, then search the tree for the nearest leaf in the requested direction. For previous/next: do an in-order traversal of leaves and return the adjacent one.
- `resize(node: *Node, current: *Surface, direction: ResizeSplit.Direction, amount: u16) void` - find the branch above the current surface that matches the resize direction, adjust its ratio by amount (as pixel delta converted to ratio change based on the branch rect size).
- `allSurfaces(node: *Node, list: *std.ArrayList(*Surface)) void` - collect all leaf surfaces for iteration.

Import RECT from App.zig or define locally. Import MoveWindow, ShowWindow from user32.

  <action>
Add performAction handlers in App.zig for split-related actions:

`.new_split` (value is SplitDirection enum: right, down, left, up):
- Get the active tab and its focused surface.
- Create a new child HWND and Surface (same pattern as createTab but for a split).
- Map SplitDirection to SplitTree.Direction: right/left -> .horizontal, down/up -> .vertical.
- Call active_tab.split(alloc, direction, new_surface).
- For left/up: the new surface should be `first` (swap after split).
- Call active_tab.layout(client_rect) to reposition all child HWNDs.
- Set focus to the new surface.
- Return true.

`.goto_split` (value is GotoSplit enum: previous, next, up, left, down, right):
- Get the active tab's SplitTree root and current focused surface.
- Call SplitTree.focusDirection(root, current, direction) to find the target surface.
- If found: update active_tab.focused_surface, call SetFocus on the target's HWND.
- Return true.

`.resize_split` (value is ResizeSplit struct: amount u16, direction Direction):
- Get the active tab's SplitTree root and current focused surface.
- Call SplitTree.resize(root, current, direction, amount).
- Call active_tab.layout(client_rect) to reposition.
- Return true.

`.equalize_splits`:
- Walk the active tab's SplitTree, set all branch ratios to 0.5.
- Call active_tab.layout(client_rect).
- Return true.

`.toggle_split_zoom`:
- If not zoomed: hide all child HWNDs except the focused surface's, resize the focused surface to fill the entire tab area, set a `zoomed: bool` flag on the tab.
- If zoomed: call active_tab.layout(client_rect) to restore normal layout, show all child HWNDs, clear zoomed flag.
- Return true.

Also update the close logic:
- When a surface closes (via close action or process exit), call active_tab.removeSurface. If the tab becomes empty, close the tab. Otherwise, re-layout.
- Update WM_SIZE handler to call active_tab.layout with the new client rect (minus tab bar height).

Add `getActiveTab(self: *App) ?*Tab` and `clientRectBelowTabBar(self: *App) RECT` helpers.
