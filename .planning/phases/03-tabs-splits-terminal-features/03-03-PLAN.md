  <action>
Create SearchOverlay.zig implementing a search UI overlay:
- The overlay is a child HWND (WS_CHILD | WS_VISIBLE) positioned at the top-right of the surface's child HWND, ~300px wide x 32px tall.
- Contains a Win32 EDIT control (text input) and two buttons (up/down navigation).
- On text change in the EDIT control (EN_CHANGE notification via WM_COMMAND): call core_surface.searchWithNeedle(text) to trigger the search. The core handles highlighting matches in the renderer.
- Up/Down buttons or Enter/Shift+Enter in the EDIT control: call core_surface.searchPrevious() / core_surface.searchNext().
- Escape key in the EDIT control: close the overlay (hide HWND, call core_surface.searchClear()).
- Store a reference to the Surface it's attached to.
- init(alloc, surface_hwnd, core_surface) creates the overlay HWND as a child of the surface HWND.
- show(needle) makes it visible and sets focus to the EDIT control, optionally pre-filling the needle.
- hide() hides the overlay and returns focus to the surface.

In App.zig, add performAction handlers:
- `.start_search`: Get the target surface (focused surface of active tab). Create a SearchOverlay if one doesn't exist on that surface, or show it. Pre-fill with value.needle if non-empty. Return true.
- `.end_search`: Hide the overlay on the target surface. Return true.
- `.search_total`: Store the total count for display in the overlay (e.g., "3/17 matches"). The overlay can read this and repaint. Return true.
- `.search_selected`: Store the selected index. Overlay repaints to show "N/total". Return true.

For the scrollbar, add to Surface.zig:
- Add `scroll_position: f64 = 1.0` (0.0 = top, 1.0 = bottom) and `scroll_visible: bool = false` fields.
- In App.zig, handle `.scrollbar` action: update the target surface's scroll_position from the terminal.Scrollbar value, set scroll_visible based on whether scrollback exists. Call InvalidateRect on the surface's HWND to trigger repaint.
- In the surface's child HWND wndProc (or a subclassed wndProc), handle WM_PAINT to draw a thin vertical scrollbar track on the right edge (~8px wide) with a thumb indicator. Use GDI FillRect with a semi-transparent appearance (use layered child window or simple gray/dark fill). The thumb position maps scroll_position to the track height.
- Handle WM_LBUTTONDOWN in the scrollbar region to set scroll position and notify core_surface.scrollToPosition.
- Handle WM_MOUSEWHEEL for scroll: already handled by core, but ensure the event reaches the surface.

Note: The surface child HWNDs need their own wndProc for WM_PAINT (scrollbar) and WM_MOUSEWHEEL. Either register a separate window class for surface child HWNDs with a custom wndProc, or use subclassing via SetWindowSubclass. The surface wndProc should forward unhandled messages to DefWindowProc. The surface wndProc also needs to handle WM_LBUTTONDOWN for scrollbar clicks vs normal mouse input.

URL click handling:

In App.zig, add performAction handler for `.open_url`:
- Extract the URL string from value.url ([]const u8).
- Convert to null-terminated UTF-16 using std.unicode.utf8ToUtf16LeStringLiteral pattern (runtime: utf8ToUtf16Le into a stack buffer, append null).
- Call ShellExecuteW(null, L("open"), url_wide, null, null, SW_SHOW) to open the URL in the default browser.
- ShellExecuteW is from shell32.dll: `extern "shell32" fn ShellExecuteW(hwnd: ?HWND, lpOperation: ?LPCWSTR, lpFile: LPCWSTR, lpParameters: ?LPCWSTR, lpDirectory: ?LPCWSTR, nShowCmd: i32) callconv(.c) isize;`
- Return true.

In App.zig, add performAction handler for `.mouse_over_link`:
- When a link is hovered (value.url is non-empty): set the cursor to IDC_HAND (hand pointer) using SetCursor(LoadCursorW(null, IDC_HAND)). Store a flag `hovering_link: bool` on the surface.
- When the link is no longer hovered (value.url is empty): restore cursor to IDC_ARROW. Clear the flag.
- The cursor change needs to persist across WM_SETCURSOR messages. Handle WM_SETCURSOR in the surface child wndProc: if hovering_link, call SetCursor(hand) and return TRUE to prevent DefWindowProc from resetting it.
- IDC_HAND = 32649.

Bell notification:

In App.zig, add performAction handler for `.ring_bell`:
- Call MessageBeep(0xFFFFFFFF) for the system default beep sound. This is the simplest audible bell.
- MessageBeep is from user32: `extern "user32" fn MessageBeep(uType: u32) callconv(.c) BOOL;`
- Optionally also flash the taskbar icon using FlashWindow(hwnd, TRUE) for visual bell.
- FlashWindow is from user32: `extern "user32" fn FlashWindow(hwnd: HWND, bInvert: BOOL) callconv(.c) BOOL;`
- Return true.

Also handle `.cell_size` action in performAction:
- Store the cell size on the surface for use in cell-snapped resize calculations.
- This was previously derived from core_surface.size.cell but having it explicitly tracked may be needed for split calculations.
- Return true.
